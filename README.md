# On-Ground Call Centre

A React frontend implementation of the On-Ground Call Centre staff application based on the provided product mock and assignment brief.

## Tech Stack

- React
- Vite
- React Router
- CSS
- Tabler Icons
- Recharts
- Local mock data

## Features

- Dashboard with agent performance KPIs
- Daily progress and earnings
- Call planning
- Calls to make
- Incoming calls
- Recent calls
- Lead details modal
- Lead pagination
- Calendar with month navigation
- Pulse AI workspace
- Team channels
- Channel chat
- Send messages
- "Needs your input" task interaction
- AvaniBot actions
- Responsive layout

## AI Tools Used

- ChatGPT — used for UI/component planning, implementation assistance,
  debugging, and code review.
